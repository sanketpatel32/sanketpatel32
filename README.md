## About

I'm a software engineer from Jamnagar, India, working on backend and AI systems at **The Algorithm**. I care about software that is fast, private, and easy to run.

- **Backend:** APIs, services, and database-driven systems that stay up
- **Developer tools:** local-first Windows apps that need no cloud or account
- **AI:** practical LLM workflows, inference, voice agents, and automation
- **Learning:** system design, distributed systems, and software architecture
